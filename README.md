# Arcanum V4 — Inteligência Estratégica

Interface Next.js para análise, planejamento e organização de conhecimento em comunicação política.

## O que foi acrescentado
- Central Estratégica com 6 planos executáveis
- Sínteses estruturadas dos estudos enviados
- Radar de temas demonstrativo
- Estúdio de conteúdo com briefings locais
- Arcanum Assistente em modo demonstração, sem API
- Alertas explícitos sobre ética, contexto, desinformação e limites dos dados

## Executar
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Vercel
Framework Preset: Next.js. Deixe Output Directory vazio.
